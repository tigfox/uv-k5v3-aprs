Using the menu

  1. If the screen is dark, the first key press only turns the backlight on (the key is not used). Then press MENU. Scroll with ▲ ▼ (UV-K1: ◀ ▶), or type the item's two-digit number (for example 08 for 08 Call).
  2. Press MENU to edit the item.
  3. Change the value with ▲ ▼. Text fields are spelled one character at a time (below).
  4. MENU saves. EXIT cancels (a text field: EXIT steps back; hold it to cancel).
  5. EXIT again leaves the menu. It also leaves by itself after a short time.

Spelling text: Call, Cmnt, MsgTo, Msg

  1. The field opens empty. A ^ under the line marks the character you are on.
  2. ▲ ▼ choose the character: blank, A–Z, 0–9, then - . / ? ! @ : , '. Hold a key to scroll. The digit keys type a digit directly and move on.
  3. * keeps the character and moves to the next one.
  4. EXIT steps back one character (hold it to cancel). MENU saves the text.

Pressing MENU on an empty field keeps the old text. A callsign is up to 6 characters without the SSID; the message text is up to 30; a comment up to 43.

A Set the callsign

  1. 08 Call: spell your callsign (no SSID).
  2. 09 SSID: choose 0–15. Give each radio its own SSID, for example -1 for the digi and -7 for a handheld. Two stations on the same call and SSID count as one.

The radio will not transmit until a real callsign is set (3 or more characters with a digit and a letter; N0CALL and NOCALL are refused). Kept through power-off.

B Set the frequency

  1. On the main screen show a frequency, not a channel (hold 3, or F then 3).
  2. Type six digits, for example 144.390 MHz: 144390.
  3. Check the display shows exactly that. The radio rounds to its step: a 12.5 kHz step turns 144.390 into 144.3875. If it moved, set 19 Step to 5 or 10 kHz and retype.

The radio tunes and transmits only inside 144–148 MHz and 420–450 MHz. Packets go out on whatever the main VFO shows, so leave it on the APRS frequency. It returns to the same frequency after a power cut.

C Receive only: read APRS messages

ItemSet toWhy
01 APRSONListens for packets.
07 IntvOFFNo automatic beacons.
02 DigiOFFDoes not repeat other stations.
  • A message to your callsign and SSID opens a box, triple beep, backlight on. Any key closes it. 22 RdMsg then MENU shows the last one again; ▲ ▼ turn its pages. It is lost at power-off.
  • Other packets show for 30 s in the box as CALL 12.3km (needs 10 Loc set) or CALL:text.
  • Not fully silent: the radio acknowledges a numbered message addressed to it.
  • While APRS is on, the radio listens on the main VFO only (dual watch is switched off) and the lower half of the main screen is the APRS panel instead of VFO B.

D Send a message

  1. 12 MsgTo: who to (N0CALL-7). After a message arrives this already holds the sender.
  2. 13 Msg: the text (30 characters).
  3. 14 Send: MENU, ▲ to SEND, MENU. It goes out within half a second when the channel is quiet. Sending the same text again is a retry (same line number); changing it gives a new number.

Check it is working

With APRS on, the lower half of the main screen shows:

LH W1AW-9 2m*
HRD  124 RPT   37
DUP    9 DRP    0

The last station heard and how long ago (*: this digi repeated it), then the counters. The red LED lights while it transmits (for a beacon, a message or a repeat).

F Before you leave for the site

  1. Battery charged; spare pack or USB-C power if the site allows.
  2. 08 Call and 09 SSID set; main VFO on the APRS frequency, display checked.
  3. 16 Power and 17 Sql chosen; 26 KeyLck on so a bump does not change settings.
  4. Digi settings from the table; 01 APRS ON. Wait for the first beacon (about 15 s) and see it on another receiver or aprs.fi.
  5. Send a packet from another radio with a WIDE1-1 path: RPT should rise and the red LED flash. If HRD rises but RPT does not, open DStat (DRP, HOP, DUP).
  6. Power-cycle once: the radio should come back on the same frequency with APRS and Digi still on.

G Flashing and recovery

Flash (UV Studio)

  1. Back up the calibration first: Dump Calibration in UV Studio, normal mode. Keep the file.
  2. Put the radio in DFU mode as UV Studio's Flash Firmware page shows, choose f4hwn.aprs.bin, flash.
  3. Stock Fusion kept in slot 1 is the way back (below).

Get the stock firmware back

  1. Power off. Hold MENU, power on, release when the slot selector appears.
  2. ▲ ▼ pick slot 1 (Fusion), MENU restores it, EXIT leaves.
  3. Never power off while a slot is restoring.

The service menu (calibration, F Lock, Reset) is still there: power on holding PTT and the upper side key. Settings made with UV Studio or CHIRP are kept; Reset clears the radio but not the APRS settings.

From a computer: USB-C or the K-plug cable. aprs_pc.py PORT status, setup get|set file.json, monitor, msg TO text. Licensed amateurs only. Firmware: UV-K5 V3 / UV-K1 APRS build, KD2DCM-APRS on the splash screen.
